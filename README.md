## 1.搭建环境零碎知识

### 1.1 commitlint >> commit-msg 常用的type
常用的type值包括如下:

- feat: 添加新功能
- fix: 修复 Bug
- chore: 一些不影响功能的更改
- docs: 专指文档的修改
- perf: 性能方面的优化
- refactor: 代码重构
- test: 添加一些测试代码等等
